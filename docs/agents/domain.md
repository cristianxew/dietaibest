# Domain Docs

## Layout

Single-context — one `CONTEXT.md` at the repo root covers the entire project.

## Files

| File | Purpose |
|------|---------|
| `CONTEXT.md` | Domain language, bounded contexts, key concepts |
| `docs/adr/` | Architectural Decision Records |

## Consumer Rules

- Read `CONTEXT.md` before architectural suggestions or writing specs.
- ADRs are numbered sequentially (`0001-title.md`) — read the most recent ones first.
- If either file/directory doesn't exist yet, note the absence and proceed.
