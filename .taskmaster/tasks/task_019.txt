# Task ID: 19
# Title: USDA-Powered Nutrition Calculator Implementation
# Status: pending
# Dependencies: None
# Priority: high
# Description: Build a complete USDA FoodData Central-powered nutrition calculator that parses recipe ingredients, searches USDA FDC, resolves portions to grams, computes accurate macros, and caches results in Supabase for performance.
# Details:
Implement a production-ready nutrition calculator with the following key features:
- Parse free-text recipe ingredients into {name, qty, unit}
- Search USDA FDC and pick best food match per ingredient (Foundation > FNDDS > SR Legacy > Branded)
- Resolve household measures (foodPortions[]) to grams with fallback to brand serving or density
- Compute accurate macros (kcal, protein, fat, carbs, fiber) per ingredient, sum totals and per-serving
- Cache FDC food details in Supabase to minimize API calls and improve speed
- All FDC calls must be server-side only (never from browser)
- Include type safety, error handling, tests, and inline documentation

Technical Stack:
- Next.js 15 (App Router) with React 18 + TypeScript 5
- Prisma ORM connected to Supabase Postgres
- ShadCN UI + Tailwind CSS
- Bun runtime & package manager
- USDA_API_KEY already set in server environment

Data Type Priority: Foundation > FNDDS > SR Legacy > Branded (unless brand specified)
TTL Strategy: Foundation/FNDDS/SR = 180 days, Branded = 30 days

# Test Strategy:
1. Unit test ingredient parsing with various formats (fractions, decimals, units)
2. Test nutrition calculation accuracy against known reference values
3. Verify portion resolution logic with FDC data types
4. Performance test caching mechanism with repeated queries
5. Integration test complete workflow from ingredient input to nutrition display
6. Test server-side API key security (no client exposure)
7. Test error handling for unrecognized ingredients and API failures
8. Acceptance test: paste sample ingredients, set servings, verify accurate calculations

## 1. Create Prisma Schema for FDC Cache and Recipe Ingredients [pending]
### Dependencies: None
### Description: Add Prisma models for FdcCache, Recipe, and RecipeIngredient to store USDA FDC data and recipe nutrition information in Supabase Postgres.
### Details:
Add the following models to prisma/schema.prisma:

```prisma
model FdcCache {
  fdcId          Int       @id
  description    String
  dataType       String
  brandOwner     String?   @db.VarChar(255)
  foodPortions   Json?     // from FDC
  foodNutrients  Json?     // from FDC (abridged or full)
  labelNutrients Json?     // Branded foods per serving info if present
  lastFetchedAt  DateTime  @default(now())

  @@index([dataType])
  @@index([description])
}

model Recipe {
  id          String   @id @default(cuid())
  title       String
  servings    Int      @default(1)
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt
  ingredients RecipeIngredient[]
}

model RecipeIngredient {
  id            String  @id @default(cuid())
  recipeId      String
  originalText  String
  nameNorm      String
  qty           Float
  unit          String
  fdcId         Int?
  gramWeight    Float?   // resolved grams for ONE unit
  confidence    Float?   // 0..1
  debugJson     Json?

  recipe        Recipe   @relation(fields: [recipeId], references: [id])

  @@index([recipeId])
  @@index([nameNorm])
}
```

After adding models, run:
```bash
bunx prisma generate
bunx prisma migrate dev --name add_fdc_nutrition
```

## 4. Create Ingredient Parser with Heuristics [pending]
### Dependencies: None
### Description: Implement src/lib/ingredients.ts with natural language parsing for recipe ingredient lines, extracting quantity, unit, and name with synonym mapping and density fallbacks.
### Details:
Create src/lib/ingredients.ts with complete implementation including:

ParsedIngredient Type:
- original: string
- name: string (normalized)
- qty: number
- unit: string (normalized)

Constants:
- FRACTIONS map (½, ¼, ¾, ⅓, ⅔, ⅛)
- UNIT_ALIASES map (grams→g, cup→cup, tablespoon→tbsp, etc.)
- STATE_WORDS array (chopped, diced, minced, boiled, cooked, raw, etc.)
- SYNONYMS map (aubergine→eggplant, courgette→zucchini, etc.)
- DENSITY_FALLBACK_G_PER_UNIT map (onion:cup→160, rice cooked:cup→158, etc.)

Functions:
- toNumber(): Parse "1 1/2" or "1½" to 1.5
- normalizeUnit(): Convert unit variations to standard forms
- parseIngredientLine(): Main parser with regex patterns

Parsing Logic:
1. Try pattern: "<qty> <unit> <name...>"
2. Fallback to: "<name...> <qty> <unit>"
3. Strip state words from name
4. Apply synonym substitutions
5. Normalize to lowercase
6. Return ParsedIngredient object

Handle edge cases:
- Fractions and decimals
- Missing units (default to "piece")
- Various spacing formats
- Plural forms

## 5. Implement Recipe Analysis Server Action [pending]
### Dependencies: 19.2, 19.3, 19.4
### Description: Create src/actions/analyzeRecipe.ts server action that orchestrates the complete nutrition analysis pipeline from ingredient lines to calculated macros.
### Details:
Create src/actions/analyzeRecipe.ts with "use server" directive implementing analyzeRecipeAction():

Input Type (AnalyzeInput):
- ingredients: string[]
- servings: number

Output Type (AnalyzeResult):
- items: Array of per-ingredient results with fdcId, description, gramsTotal, macros, confidence, portionNote
- total: Aggregated macros for entire recipe
- perServing: Total macros divided by servings

Pipeline Steps:
1. Parse all ingredient lines using parseIngredientLine()
2. Search USDA FDC for each ingredient name (parallel Promise.all)
3. Choose best match per ingredient using DATATYPE_PRIORITY sorting
4. Batch fetch full food details via getFoodsCached()
5. For each ingredient, resolve gram weight:
   a. Try resolveGramWeightFromPortions() for household measures
   b. Try extractBrandedServing() for branded foods
   c. Try DENSITY_FALLBACK_G_PER_UNIT lookup
   d. Fall back to assuming grams or qty as grams
6. Extract per-100g macros and scale to actual grams
7. Compute confidence scores based on resolution method
8. Aggregate totals across all ingredients
9. Calculate per-serving macros

Include portionNote for each ingredient explaining resolution method.

Handle cases where no FDC match found (return zeros with confidence 0).
