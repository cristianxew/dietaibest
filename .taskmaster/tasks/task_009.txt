# Task ID: 9
# Title: AI-Powered Meal Plan Generation
# Status: pending
# Dependencies: 1, 2, 5, 7, 8
# Priority: high
# Description: Integrate Edamam's Meal Planner API to automate meal plan generation based on user preferences, dietary restrictions, and nutritional targets. Build an interface for user input, source selection, and plan customization, leveraging Edamam's features such as multi-week planning, nutrient personalization, diet/health labels, shopping list generation, and AI Assistant support.
# Details:
1. Build user input interface to collect preferences, dietary restrictions, and nutritional targets
2. Implement source selection (in-house recipes, favorites, Edamam API, or mixed)
3. Integrate with Edamam Meal Planner API endpoints for meal plan generation
4. Construct and validate API request payloads based on user input
5. Handle API responses and display generated meal plans, including up to 2 weeks of planning and 28 nutrients
6. Display and manage diet/health labels (up to 40 supported by Edamam)
7. Show automatically generated shopping lists from Edamam
8. Provide plan adjustment and fine-tuning interface (e.g., swap meals, adjust servings)
9. Implement plan regeneration for specific days/meals via Edamam API
10. Add loading states, skeleton UI, and progress tracking (SSE if supported by Edamam)
11. Implement robust error handling for API failures and invalid responses
12. Create success/error toast notifications
13. Enable plan saving and export after generation
14. Build tolerance checking (±5% of target macros, using Edamam's nutrient data)
